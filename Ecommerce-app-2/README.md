Welcome to the E-commerce App:

In the App the user can:
    Add, Edit, and Delete Customers
    Add, Edit, and Delete Products
    Place Orders

Everthing is run through REACT infrastructure working with a flask app to store, organize, and call the necessary data. 

Enter the application by running:

    cd Ecommerce-app-2
    
Intiate the application by running

    npm run dev

The menu bar can be used to navigate the application. Clicking "Home" or "E-commerce App" will return users to the main page.
